# HistoryMaP - Historical Events Map

A web application that displays interactive clickable map of historical events.
Users can click on different geographical locations to discover interesting
historical facts about specific areas and time periods.

## Features
- Interactive map with geographical coordinates
- Clickable regions showing historical events
- Timeline-based event filtering
- Educational content about world history

## Tech Stack
- Frontend: HTML/CSS/JavaScript (vanilla or framework)
- Backend: Python Flask/FastAPI
- Data: JSON files with location and historical event data

## Getting Started
```bash
cd backend
pip install -r requirements.txt
python app.py
```

## Project Structure
- `frontend/` - Web interface (HTML/CSS/JS)
- `backend/` - Python server with API endpoints
- `data/` - Historical events data in JSON format
